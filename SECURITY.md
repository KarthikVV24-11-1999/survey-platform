# Security

If you find a security issue, please don't open a public issue. Use the "Report a vulnerability" option under the repository's Security tab instead, with steps to reproduce if you can.

Issues in third-party services (Vercel, Neon, Cloudflare, OpenAI, Google, GitHub) should go to those providers.

More on how the app is protected is in [docs/security.md](docs/security.md).
